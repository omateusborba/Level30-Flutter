# Ícone Android - Level 30

Arquivos gerados a partir da imagem enviada.

## Como usar no Android Studio
1. Descompacte este ZIP.
2. Copie a pasta `res` para:
   `app/src/main/res/`
3. Confirme no `AndroidManifest.xml`:
   `android:icon="@mipmap/ic_launcher"`
   `android:roundIcon="@mipmap/ic_launcher_round"`

## O que foi incluído
- Ícone adaptativo Android 8+:
  - `mipmap-anydpi-v26/ic_launcher.xml`
  - `mipmap-anydpi-v26/ic_launcher_round.xml`
  - foreground em mdpi, hdpi, xhdpi, xxhdpi e xxxhdpi
  - monochrome layer para themed icons
- Ícones legados:
  - `ic_launcher.png`
  - `ic_launcher_round.png`
- Ícone para Google Play:
  - `play_store/icon_512.png`
- Previews:
  - square, circle e rounded
