# Telas do app Flutter

Capturas de 2026-10-28, usuária de demonstração (Ana Souza), viewport de celular 390×844 em resolução 2x.

Como foram geradas: não há simulador iOS, SDK Android nem Xcode nesta máquina, então o app foi compilado para
**web (Chrome)** numa cópia temporária do projeto (o repositório não foi alterado), apontando para a API local
(`--dart-define=API_BASE_URL=http://localhost:8080`). O código Dart é o mesmo do app; o visual nativo
(barra de status, teclado, mapa nativo) pode diferir levemente em um aparelho real.
